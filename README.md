# Análise de Dados em Telecom com SQL e Power BI

## Sobre o projeto
Este projeto foi desenvolvido com foco em análise de dados do setor de telecom, utilizando uma base com indicadores de desempenho e qualidade de serviços.

O objetivo foi transformar dados brutos em análises visuais e consultas que ajudassem a entender o comportamento das empresas, dos serviços prestados e da evolução dos resultados ao longo do tempo.

## Ferramentas utilizadas
- SQL
- Power BI
- CSV
