# Observações do Projeto

## Tratamento dos dados
- valores com `%` foram ajustados para formato numérico quando necessário
- valores `NI` foram tratados como nulos ou mantidos conforme o contexto da análise
- valores `NO` foram avaliados conforme o significado no conjunto de dados
- a coluna de resultados foi preparada para uso nos visuais do Power BI

## Dashboard
- o card de total de registros foi criado com base na coluna de resultados
- foi adicionada uma segmentação de dados por serviços prestados
- o dashboard foi pensado para visão executiva e comparação entre empresas
